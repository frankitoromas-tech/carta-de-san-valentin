Aplicación web interactiva, lúdica y animada creada para celebraciones de San Valentín. Cuenta con animaciones fluidas, microinteracciones dinámicas para los botones de respuesta y una experiencia visual enriquecida con ilustraciones y tipografías personalizadas de Google Fonts (*Pacifico* & *Quicksand*).

---

## ✨ Características Principales

- **🎮 Microinteracciones Divertidas:** El botón de respuesta negativa esquiva dinámicamente el cursor o clic del usuario mediante cálculo vectorial de coordenadas en JavaScript.
- **🎨 Animaciones CSS3:** Efectos de transición suaves, flotación de corazones y cambios dinámicos de estado visual.
- **📱 100% Responsivo:** Adaptado para visualizarse con total fidelidad en dispositivos móviles, tablets y monitores de escritorio.
- **⚡ Cero Dependencias:** Construido exclusivamente con tecnologías web nativas (Vanilla HTML5, CSS3 puro y JavaScript moderno).
